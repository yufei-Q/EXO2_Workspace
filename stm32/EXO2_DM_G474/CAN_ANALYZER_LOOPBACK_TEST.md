# CAN 分析仪收发测试

本测试用于检查 STM32G474、CAN FD 收发器、总线接线以及 CAN 分析仪之间的双向通信。

## 安全准备

测试时先断开 7 台电机，或至少断开电机动力电源，避免测试帧被电机误处理。总线两端各保留一个 120 Ω 终端电阻，断电测量 CAN_H 与 CAN_L 之间应约为 60 Ω。

## CAN 分析仪参数

- 工作模式：Normal / Active，不要选择 Listen Only
- 帧格式：CAN FD with Bit Rate Switching（BRS）
- 仲裁段波特率：1 Mbit/s
- 数据段波特率：4 Mbit/s
- 标识符：Standard ID（11 位）
- 数据长度：8 字节

这些参数必须和 CubeMX 中的 FDCAN1 配置一致。

## STM32 主动发送测试

烧录并复位后，分析仪应每 100 ms 收到一帧：

- CAN ID：`0x100`
- 帧类型：CAN FD + BRS，数据帧
- DLC：8
- 数据：`A5 5A XX XX XX XX 47 34`

第 2～5 字节是小端格式的 32 位递增计数器。例如，开始几帧应为：

```text
A5 5A 00 00 00 00 47 34
A5 5A 01 00 00 00 47 34
A5 5A 02 00 00 00 47 34
```

能连续收到这些帧，说明 STM32 到分析仪的发送链路正常。

## 分析仪发送与 STM32 回传测试

从分析仪发送以下帧：

- CAN ID：`0x200`
- 帧类型：CAN FD + BRS，数据帧
- DLC：8
- 示例数据：`01 02 03 04 05 06 07 08`

STM32 收到后应立即回传：

- CAN ID：`0x201`
- 数据：与收到的 8 字节完全相同

示例回传为 `01 02 03 04 05 06 07 08`。能收到回传说明分析仪到 STM32 的接收链路也正常。

## 恢复正常电机控制

打开 `Core/Inc/main.h`，把：

```c
#define CAN_ANALYZER_LOOPBACK_TEST  1U
```

改为：

```c
#define CAN_ANALYZER_LOOPBACK_TEST  0U
```

然后重新编译并烧录。设为 `0U` 后会恢复原来的 USB 通信、500 Hz 定时控制和 7 台电机控制代码，不需要删除本次加入的测试函数。
